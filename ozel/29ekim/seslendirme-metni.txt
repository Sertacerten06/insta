29 EKİM ÖZEL: SESLENDİRME METNİ
(Kendi sesinle okumak istersen: sakin, belgesel tonunda. // = kısa durak)

[kanca]
29 Ekim 1923. // Akşam, saat sekiz buçuk. // Ankara'daki mecliste 158 milletvekili, aynı karara evet diyor. // Peki bu ana nasıl gelindi?

[acilis]
Gel, Cumhuriyet'e giden dört yılı birlikte yürüyelim.

[y1919]
1918'in sonu. // Osmanlı, savaştan yenik çıkmış. // Mondros'la birlikte, ülkenin dört bir yanı işgal ediliyor. // 19 Mayıs 1919'da, Mustafa Kemal Samsun'a çıkıyor. // Amasya'da, bütün yurda şu sözle sesleniyor: // Milletin istiklalini, yine milletin azim ve kararı kurtaracaktır.

[defter]
Temmuz'da yol Erzurum'a uzanıyor. // Bir gece, yakın arkadaşı Mazhar Müfit'e bir not yazdırıyor: // Zaferden sonra, hükümet biçimi Cumhuriyet olacaktır. // Ve bu sayfanın, şimdilik kimseye gösterilmemesini istiyor. // Erzurum ve Sivas kongreleriyle, millet artık tek ses.

[y1920]
23 Nisan 1920. // Ankara'da Büyük Millet Meclisi açılıyor. // Sakarya'da, yirmi iki gün yirmi iki gece süren savaş kazanılıyor. // 26 Ağustos 1922'de Büyük Taarruz başlıyor. // 9 Eylül'de, ordu İzmir'de. // 1 Kasım'da da saltanat kaldırılıyor.

[y1923]
Ve 1923. // 24 Temmuz'da Lozan imzalanıyor. // 13 Ekim'de Ankara, başkent oluyor. // 28 Ekim akşamı, Çankaya'daki yemekte Mustafa Kemal, arkadaşlarına dönüp şöyle diyor: // Yarın, Cumhuriyet'i ilan edeceğiz.

[ilan]
Ertesi akşam, meclis tarihi kararı veriyor: // Türkiye Devleti'nin hükümet şekli, Cumhuriyettir. // Gazi Mustafa Kemal, oy birliğiyle ilk Cumhurbaşkanı seçiliyor. // Ankara'nın gökyüzünde, 101 pare top.

[kapanis]
Erzurum'da bir deftere sessizce yazılan o cümle, // dört yıl sonra, bütün bir milletin geleceği oldu. // Cumhuriyetimizin 103. yılı kutlu olsun.
